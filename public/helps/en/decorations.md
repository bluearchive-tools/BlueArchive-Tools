# Decoration Shop Guide

## Purchase
- Use the **Purchase** button to buy decorations.
- Non-credit items **cannot be purchased again if already owned**.
- The “Daily 1000 Credits” pack can be claimed **once per day**.

## Equip & Categories
- Only **one item per category** (frame, background, font, etc.) can be equipped.
- Equipping an item in the same category replaces the previous one.
- Preview reflects category conflicts and shows the currently previewed item as equipped.

## Admin Tools
- Admins can manage items with **Add**, **Delete**, and **Edit** buttons.
- Editing lets you change name, description, price, tags, colors, fonts, and style flags; changes apply immediately to the list.

## FAQ
- **Text is hard to read**: Text color is auto-adjusted to the background. For fine-tuning, edit the item as an admin.
- **Switch categories**: Equipping another item in the same category will replace the current one. Use Preview to confirm before saving.
