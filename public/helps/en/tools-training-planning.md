# Training planning

- Select a student to load current status from saved data (if available).
- Current status is shown on the left, and editable target status is on the right.
- When switching students, target fields are automatically synced to current values.
- Automatically calculates required resources for star, unique weapon star, level, equipment, skill, and bond goals.

## Notes
- Level EXP uses the student level EXP table (Lv1-90).
- Equipment EXP uses a separate equipment EXP table (Lv1-70), distinct from level EXP.
