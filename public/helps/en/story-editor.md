# Story Editor

Create and preview Blue Archive style dialogue scenes.

## Quick start

1. Add characters and expressions in **Characters**
2. Add backgrounds, lines, and choices in **Timeline**
3. Preview the flow in **Story**

## Tips

- Open help with the `?` button or shortcut
- Use flags for branch conditions
- Control sprite show/hide and position with sprite cues
- Auto-fetch expressions from Blue Archive Wiki
