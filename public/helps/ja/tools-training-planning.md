# 育成プランニング

- 生徒を選択すると、保存データ（存在する場合）から現在ステータスを読み込みます。
- 左側に現在ステータス、右側に目標ステータス（自由入力）を表示します。
- 「すべて最大にする」で目標を一括設定できます。
  - 星5 / 固有★4 / レベル90 / 装備70 / スキル最大
  - 絆は通常そのまま、Ctrl(Cmd)+クリック時のみ絆50
- 星と固有で必要な生徒神名文字を合算して表示します。

## 複数生徒プラン
- 「この生徒をプランに追加/更新」で複数生徒を保存できます。
- 各生徒の必要神名文字を合算して表示します。
- 「計算結果の詳細」ボタンからモーダルを開き、
  - 現在所持の生徒神名文字
  - 交換レート
  - 残り交換可能数
  を設定して、神名文字交換通貨の必要量を確認できます。

## 計算メモ
- レベル経験値は生徒経験値テーブル（Lv1〜90）を使用します。
- 装備経験値は装備経験値テーブル（Lv1〜70）を使用し、レベル経験値とは別で計算します。
